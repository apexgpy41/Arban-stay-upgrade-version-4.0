## 📖 About

UrbanStay is a modern **full-stack web application** that helps students find rental rooms and PG accommodations near colleges. It offers a fast, secure, and user-friendly experience with authentication, property management, online payments, maps, and reviews.

---

## ✨ Key Features

* 🔐 Secure Authentication (JWT & Google Sign-In)
* 🏠 Browse & Search Rental Rooms
* 📍 Interactive Maps
* ❤️ Wishlist / Favorites
* ⭐ Ratings & Reviews
* 💳 Online Payments (Razorpay)
* 📷 Image Upload (Cloudinary)
* 👤 User Dashboard
* 🛠️ Admin Dashboard
* 📱 Fully Responsive Design

# 🚀 Installation

## Clone

```bash
git clone https://github.com/YOUR_USERNAME/UrbanStay.git
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
npm install
npm start
```

---

# 🔑 Environment Variables

Create a `.env` file.

```env
MONGODB_URI=
JWT_SECRET=

FIREBASE_API_KEY=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=

RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=

TWILIO_ACCOUNT_SID=
TWILIO_AUTH_TOKEN=
```

⚠️ Never upload your `.env` file.
